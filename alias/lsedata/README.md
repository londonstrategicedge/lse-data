# lsedata

This package protects the unhyphenated spelling of
[lse-data](https://pypi.org/project/lse-data/), the official London Strategic
Edge Python client. Installing `lsedata` installs `lse-data`; the import is the
same either way:

```python
import lse
```

Install the real package directly:

```
pip install lse-data
```

Source and documentation: https://github.com/londonstrategicedge/lse-data
